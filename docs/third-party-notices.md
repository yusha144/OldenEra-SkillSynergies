# Сторонние компоненты

Код Skill Synergies, установщика и документация распространяются по [MIT](../LICENSE).

Мод использует BepInEx, Il2CppInterop и интерфейсы Unity. Их двоичные файлы не входят в репозиторий и установочный ZIP Skill Synergies. При отсутствии нужных файлов установщик скачивает зависимости с серверов BepInEx:

- [BepInEx 6.0.0-be.788](https://builds.bepinex.dev/projects/bepinex_be): [исходники 5b766a3](https://github.com/BepInEx/BepInEx/tree/5b766a3), [лицензия](https://github.com/BepInEx/BepInEx/blob/5b766a3/LICENSE).
- [Базовые библиотеки Unity 6000.0.66](https://unity.bepinex.dev/libraries/6000.0.66.zip).

Адреса и контрольные суммы зависимостей зафиксированы в установщике. Компоненты сохраняют условия своих правообладателей.

Skill Synergies является неофициальным модом для Heroes of Might and Magic: Olden Era. Демонстрационные снимки содержат графику и интерфейс игры. MIT проекта не предоставляет прав на эти сторонние элементы изображений. Игровые ресурсы отдельно не распространяются.
