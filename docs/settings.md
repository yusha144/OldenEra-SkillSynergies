# Настройки Skill Synergies

## 1. Видимость подсказок

Настройки находятся в папке игры: `BepInEx/config/local.oldenera.skillsynergies.cfg`. Файл создаётся при первом запуске мода. Изменяйте его при закрытой игре.

| Секция | Параметр | По умолчанию | Действие |
|---|---|---|---|
| Display | Enabled | true | Начальная видимость подсказок после запуска игры |

F9 переключает видимость только в открытом окне выбора навыков или перков. Этот выбор действует до завершения игры и не переписывает Enabled. При следующем запуске используется значение из файла.

## 2. Клавиша переключения

Общие клавиши находятся в `BepInEx/config/OldenEra.hotkeys.cfg`. Если этого файла нет, мод читает существующий `yusha144.hotkeys.cfg`. Если нет обоих файлов, создаётся `OldenEra.hotkeys.cfg`.

В секции `Hotkeys` параметр `SkillSynergies` задаёт клавишу переключения. По умолчанию это F9. Пример изменения одной записи:

```ini
[Hotkeys]
SkillSynergies = F9 + LeftControl
```

Сохраните остальные записи файла. Значение `None` отключает клавишу. После изменения перезапустите игру.

## 3. Как читаются подсказки

Плашка относится к варианту выбора, рядом с которым она расположена.

При выборе навыка мод показывает изменение уже изученного перка. Строка источника указывает навык, к которому относится этот перк, на текущем уровне героя.

При выборе перка мод показывает его усиление имеющимися навыками. Для нескольких источников одного эффекта указываются общий итог, базовое значение перка и отдельные вклады. Новое усиление в составе расчёта отмечается словами после выбора.

Условия действия находятся отдельным блоком: например, начало раунда, тип цели или территория. Значения здоровья и лечения выделяются зелёным, золота и ресурсов золотистым, маны голубым.

Подсказки учитывают текущие варианты выбора и уже приобретённые способности героя. Для временно действующего перка указывается его временный статус. Сам мод читает данные игры и отображает результат; выбор способностей и применение бонусов выполняет игра.

## 4. Размещение

Подсказки появляются автоматически в обычном окне повышения уровня и в арене. Размер текста сохраняется при длинном содержимом. Для прокрутки наведите курсор на плашку и используйте колёсико мыши.

Если рядом с карточкой нет свободного места, остаётся отметка на самой карточке. При смене героя, набора вариантов или этапа выбора прокрутка сбрасывается. Закрытие окна убирает подсказки.

## 5. Журнал

Сообщения находятся в `BepInEx/LogOutput.log`.

- `Skill Synergies 0.1.15 loaded`: DLL загружена, каталог сочетаний прочитан.
- `Skill hint updater running`: обработчик подсказок начал работу.
- `Level-up hints`: сведения о текущем выборе и найденных сочетаниях.
- `unsupported game build`: игровые файлы отличаются от поддерживаемой сборки.
- `Synergy UI paused` или `Skill Synergies could not start`: ошибка подсказок или запуска.
