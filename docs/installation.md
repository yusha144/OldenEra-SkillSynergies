# Установка и удаление SkillSynergies

## 1. Требования

Windows x64 и установленная Heroes of Might and Magic: Olden Era, Steam build 25672315.

Для первой установки нужен интернет. Установщик загружает BepInEx Unity.IL2CPP 6.0.0-be.788 и базовые библиотеки Unity 6000.0.66 с серверов BepInEx, затем проверяет их SHA-256. Уже установленные совпадающие зависимости повторно не скачиваются.

## 2. Установка

1. Скачайте [установочный архив OldenEra-SkillSynergies-0.1.15.zip](https://github.com/yusha144/OldenEra-SkillSynergies/releases/download/v0.1.15/OldenEra-SkillSynergies-0.1.15.zip).
2. Полностью распакуйте его в отдельную папку вне каталога игры. В корне находятся `Install.bat`, `Uninstall.bat` и папка `_files`.
3. Закройте игру и запустите `Install.bat` из корня распакованного архива.
4. Проверьте путь к папке с `HeroesOldenEra.exe`. Если найдено несколько копий игры, выберите нужную. Если игра не найдена, введите путь.
5. Подтвердите установку и дождитесь сообщения об успешном завершении.
6. Запустите игру через Steam.

Первый запуск с BepInEx занимает дополнительное время на создание библиотек мода.

Кнопка `Code / Download ZIP` создаёт архив исходников с папкой `OldenEra-SkillSynergies-main`. Ссылки `Source code` на странице выпуска также содержат исходники для разработки.

Для проверки целостности установочного ZIP сравните SHA-256 с соседним файлом `.zip.sha256`:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'
```

DLL мода устанавливается в `BepInEx/plugins/SkillSynergies/OldenEra.SkillSynergies.dll`. Предыдущие файлы сохраняются в `BepInEx/SkillSynergies-backups/<дата-идентификатор>`. Старые дубликаты DLL внутри plugins также сохраняются в копии и убираются.

Установщик сохраняет существующие настройки. При обнаружении отличающегося загрузчика или отключённого `doorstop_config.ini` он останавливается с сообщением. При ошибке записи выполняется откат заменённых файлов; результат выводится в окне установщика.

## 3. Проверка работы

Откройте окно повышения уровня у героя с подходящим сочетанием. Рядом с вариантом выбора появляется плашка с эффектом и источником. F9 скрывает и показывает подсказки в этом окне.

В `BepInEx/LogOutput.log` успешная загрузка отмечена строкой `Skill Synergies 0.1.15 loaded`. Сообщение `unsupported game build` означает несовместимость игровых файлов.

Начальная видимость и клавиша переключения меняются в [настройках](settings.md).

## 4. Обновление и откат

Для обновления распакуйте новый установочный архив отдельно, закройте игру и запустите его `Install.bat`. Удалять старую версию перед этим не нужно. Настройки SkillSynergies, общие клавиши и другие моды сохраняются. Если все файлы этой сборки уже установлены, установщик сообщает: Ничего менять не нужно. Он устанавливает сборку из своего архива и не ищет новые версии в интернете.

Для отката откройте резервную копию по пути из окна установщика. При закрытой игре верните прежнюю DLL в `BepInEx/plugins/SkillSynergies`. При необходимости верните файл `local.oldenera.skillsynergies.cfg` из копии.

Файл `backup.json` перечисляет сохранённые файлы. Восстанавливайте нужные файлы по отдельности. Дубликаты DLL в других папках plugins возвращать не нужно. Общий файл клавиш перед восстановлением сравните с текущим, чтобы сохранить изменения других модов. Откат DLL не меняет версию игры.

## 5. Удаление

Закройте игру и запустите `Uninstall.bat`. Проверьте путь и подтвердите удаление.

Удаление убирает все копии `OldenEra.SkillSynergies.dll` внутри plugins. Настройки SkillSynergies, общие клавиши, резервные копии, BepInEx и другие моды остаются на месте. Интернет для удаления не нужен.

Для сброса настроек удалите только `BepInEx/config/local.oldenera.skillsynergies.cfg`.

Без установочного архива можно удалить DLL SkillSynergies и её дубликаты вручную при закрытой игре. Всю папку BepInEx удалять не нужно.

## 6. Если возникла ошибка

| Сообщение или симптом | Действие |
|---|---|
| Это архив исходников SkillSynergies / Это исходники установщика | Скачайте установочный архив по ссылке в разделе 2 и распакуйте его целиком |
| Параметр -File: файл installer\_files\Install.ps1 не существует | Открыт старый архив исходников. Скачайте установочный архив по ссылке в разделе 2 |
| Версия игры не подходит | Сверьте Steam build с требованиями |
| Другой или изменённый загрузчик | Укажите установленную версию BepInEx в обращении к автору |
| Загрузка не удалась | Проверьте доступ к серверам BepInEx и повторите установку |
| Отказано в доступе | Закройте игру и проверьте право записи в выбранную папку |
| Нет подсказок | Откройте выбор навыков с подходящим сочетанием, проверьте F9, Display.Enabled и журнал |
| Текст не помещается в плашке | Наведите на неё курсор и прокрутите колёсиком; при ошибке расположения приложите снимок |

Проверка совместимости без установки запускается из папки распакованного архива:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_files\Install.ps1 -GamePath '<папка игры>' -VerifyOnly -NonInteractive
```

В этом режиме нет скачивания и изменения файлов игры.
