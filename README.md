# Skill Synergies

Подсказки о сочетаниях предлагаемых и уже изученных навыков.

Автор: yusha144.

Проект готовится к самостоятельным выпускам. Опубликованная история исходников и готовый выпуск для игроков имеют разный статус. Проверенный архив появится в [Releases](https://github.com/Devourer22/OldenEra-SkillSynergies/releases); наличие кода на GitHub само по себе не означает, что выпуск уже опубликован.

- [Установка, настройка и обновление](Docs/ops-admin.md).
- [Устройство, параметры и ограничения](Docs/general.md).
- [Сборка и публикация версии](Docs/publishing.md).
- [Сообщить об ошибке](https://github.com/Devourer22/OldenEra-SkillSynergies/issues).

Требования: Windows x64, Heroes of Might and Magic: Olden Era, Steam build 25672315, BepInEx Unity.IL2CPP 6.0.0-be.788. Готовый архив содержит только этот мод и документацию. Загрузчик устанавливается отдельно.

Учитываются только поддержанные условия и формы эффектов. Неизвестные условия пропускаются и отражаются в журнале. Отсутствие плашки не доказывает отсутствие любого возможного сочетания.

Исходники находятся в `source/`, автоматические проверки в `tests/`. Команда `Build-Release.ps1` собирает выбранный коммит в отдельной временной папке. Для разработки нужен .NET SDK 8 или новее, среда .NET 8 для проверок и библиотеки из своей установленной игры.

Старые инструкции в корне сохранены для истории. Для отдельных архивов используйте инструкции из `Docs/`; общий установщик для них не требуется. Старые DLL сохранены в истории Git, новые сборки в неё не добавляются.

Лицензия авторского кода пока не выбрана. BepInEx и игровые библиотеки являются сторонними компонентами и в архив мода не входят.
