# Установка и сопровождение Skill Synergies

## 1. Требования и состав

Нужна собственная установленная игра Heroes of Might and Magic: Olden Era для Windows x64, Steam build 25672315, и BepInEx Unity.IL2CPP win-x64 6.0.0-be.788.

Загрузчик можно получить на [странице сборок BepInEx](https://builds.bepinex.dev/projects/bepinex_be). Для этой версии мода использована именно сборка 788. Общий порядок установки описан в [документации BepInEx](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html). После установки загрузчика самостоятельно запустите игру один раз для создания конфигурации и библиотек, затем закройте её. Не заменяйте уже настроенный другой загрузчик без проверки совместимости.

Архив мода содержит `BepInEx/plugins/SkillSynergies/OldenEra.SkillSynergies.dll`, документацию и `release-manifest.json`. Файлов самой игры, загрузчика и личных настроек в нём нет.

## 2. Установка

1. Откройте [Releases](https://github.com/Devourer22/OldenEra-SkillSynergies/releases). Выберите подходящую опубликованную версию и скачайте ZIP с названием `OldenEra-SkillSynergies-<версия>.zip` и соседний файл `.zip.sha256`.
2. Сравните результат `Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'` с контрольной суммой. Автоматические архивы GitHub Source code содержат исходники; для установки нужен архив мода.
3. Закройте игру. Если раньше устанавливали этот мод, сохраните его DLL и конфигурацию в отдельную папку вне `BepInEx/plugins`.
4. Распакуйте архив в отдельную папку. Скопируйте каталог `BepInEx` из него в папку игры, где находится `HeroesOldenEra.exe`. Не оставляйте другую копию `OldenEra.SkillSynergies.dll` в иных подпапках `BepInEx/plugins`.
5. Запустите игру обычным способом. Проверьте сообщения мода в `BepInEx/LogOutput.log`.

Пока в Releases нет опубликованного архива, готовой публичной поставки нет. Разработчик может собрать её по [инструкции публикации](publishing.md).

## 3. Настройка

При закрытой игре откройте `BepInEx/config/local.oldenera.skillsynergies.cfg`. В секции `Display` параметр `Enabled = true` включает начальную видимость. Для отключения задайте `false`. Сохраните файл и снова запустите игру.

Файл общих клавиш определяется реализацией `source/HotkeySettings.cs`: в исходной опубликованной версии это `BepInEx/config/yusha144.hotkeys.cfg`. Новые рабочие изменения переводят его на `OldenEra.hotkeys.cfg`; при выпуске этих изменений документацию нужно обновить вместе с кодом. В секции `Hotkeys` параметр `SkillSynergies` по умолчанию равен `F9`. Настройки загружаются один раз при старте.

[Остальные параметры и ограничения](general.md).

## 4. Проверка в игре

Откройте выбор навыка у героя с подходящим сочетанием. У соответствующей карточки появится подсказка. F9 скрывает и показывает подсказки в этом окне.

Успешная загрузка DLL не заменяет эту проверку. После обновления игры при отказе по контрольной сумме дождитесь совместимого выпуска; проверку сборки отключать не следует.

## 5. Обновление и удаление

Для обновления закройте игру, сохраните текущую DLL и настройки вне папки плагинов, затем замените только каталог `BepInEx/plugins/SkillSynergies` файлами нового архива. Настройки остаются на месте. Проверьте журнал и сценарий из раздела 4.

Для отката при совместимой версии игры верните сохранённую DLL и её конфигурацию. Откат мода не восстанавливает прежнюю версию игры.

Для удаления при закрытой игре удалите каталог `BepInEx/plugins/SkillSynergies`. Файл `local.oldenera.skillsynergies.cfg` можно сохранить или удалить отдельно. Общий загрузчик, файл общих клавиш и остальные моды оставьте на месте.

## 6. Если подсказок нет

Проверьте наличие загрузчика, путь и отсутствие дубликатов DLL, `Display.Enabled`, совместимость игровых файлов и журнал. Плашки появляются только при поддержанном сочетании предлагаемых и уже изученных навыков.
